# Track visor_home_20260314: 建立具備沉浸式動畫的 VISOR 系統介紹首頁\n\n## 1. 概述\n本 Track 旨在實作 VISOR 系統的門面——一個具備強烈交互感、專業科技感的介紹首頁。這不僅是用戶進入應用的第一印象，也是展示系統核心能力（定位、通訊、數據分析）的舞台。\n\n## 2. 用戶故事\n- 作為新用戶，我希望進入應用時看到流暢的動畫，感受到系統的專業性。\n- 作為用戶，我希望透過直觀的圖標和圖表預覽，快速了解 VISOR 的核心功能。\n- 作為用戶，我希望在手機上操作時，介面響應迅速且具備良好的觸控回饋。\n\n## 3. 關鍵功能\n- **沉浸式 Hero 區域**：使用深色背景、霓虹光效與流暢的文字/圖形動畫。\n- **響應式導航**：針對行動端優化的側邊欄或頂部菜單。\n- **功能矩陣**：利用 Lucide 圖標展示 GPS、藍牙、SMS 和圖表功能。\n- **數據預覽卡片**：使用 Recharts 實作一個動態的模擬數據圖表。\n- **交互回饋**：所有按鈕和卡片均具備懸停與點擊的縮放/發光效果。\n\n## 4. 技術規範\n- **框架**：React + Tailwind CSS\n- **動畫庫**：建議引入 Framer Motion 以實現「沉浸式流暢動畫」。\n- **圖表**：Recharts\n- **圖標**：Lucide\n- **適配**：優先適配 Android 行動端螢幕。
