# 技術棧 (Tech Stack)\n\n## 移動框架 (Mobile Framework)\n- **Apache Cordova (v14.0.1)**：用於跨平台移動應用程式開發。\n- **支援平台**：Android。\n\n## 前端框架與庫 (Frontend Frameworks & Libraries)\n- **React**：核心 UI 框架。\n- **Leaflet.js (v1.9.4)**：地圖與定位顯示。\n- **Recharts (v2.12.7)**：數據視覺化圖表。\n- **Tailwind CSS (v3.4.5)**：實用的 CSS 框架，用於響應式設計。\n- **Lucide (v0.407.0)**：美觀且一致的圖標庫。\n- **Marked (v12.0.2)**：處理 Markdown 內容。\n\n## 移動插件 (Mobile Plugins)\n- **cordova-plugin-geolocation**：獲取精確的位置資訊。\n- **cordova-plugin-bluetooth-serial**：與藍牙設備進行串列通訊。\n- **cordova-plugin-sms**：發送簡訊通知或警報。\n- **cordova-plugin-network-information**：監測網路連線狀態。\n- **cordova-plugin-statusbar**：管理狀態欄顯示。\n\n## 開發語言 (Languages)\n- **JavaScript (ES6+)**：主要的開發語言。\n
